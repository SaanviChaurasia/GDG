How to connect Google Classroom
  1. In Google Cloud Console, create a project and enable the Google Classroom API.
  2. Configure the Google Auth Platform consent screen and add your account as a test user while the app is in testing.
  3. Create an OAuth 2.0 Web application client. Add http://localhost:4173/auth/google/callback as an authorized redirect URI.
  4. Copy .env.example to .env inside outputs, add the OAuth client values there, then restart Evently.
  5. Choose Connect Google Classroom, sign in with your class Google account, approve read-only access, then choose Sync now.

Google handles your sign-in. Evently never asks for your Google password. The first connection needs an OAuth client configured by the site administrator.

How to connect Google Classroom
  1. In Google Cloud Console, create a project and enable the Google Classroom API.
  2. Configure Google Auth Platform consent screen and add your account as a test user while the app is in testing.
  3. Create an OAuth 2.0 Web application client. Add http://localhost:4173/auth/google/callback as an authorized redirect URI.
  4. Before starting the server, set GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET in the server environment. Restart Evently after setting them.
  5. Choose Connect Google Classroom, sign in through the Google account used for classes, approve read-only access, then choose Sync now.

Google handles sign-in; Evently never asks for your Google password. The first connection needs an OAuth client configured by the site administrator.
